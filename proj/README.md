# زراعة — نسخة HTML ثابتة

هذه نسخة عرض ثابتة لمنصة المعدات والخدمات الزراعية، معدّة للنشر على GitHub Pages.

## تشغيل الصفحة محلياً

افتح `index.html` في المتصفح، أو شغّل Apache من XAMPP ثم افتح:

`http://localhost/مشروع_ندوة_معدل/proj/index.html`

## النشر على GitHub Pages

1. ارفع ملفات الموقع إلى مستودع GitHub.
2. من **Settings → Pages** اختر الفرع الذي رفعت إليه الملفات ومجلد الجذر (`/root`).
3. انتظر اكتمال النشر. سيكون `index.html` الصفحة الرئيسية.

## حدود النسخة الثابتة

GitHub Pages لا يشغّل PHP ولا يوفر قاعدة بيانات أو جلسات. لذلك صفحات تسجيل الدخول وإنشاء الحساب والحجوزات ولوحات التحكم هنا للعرض فقط، ولا تحفظ أو تحدّث بيانات.

لا ترفع مجلد `storage/` إلى مستودع عام؛ قد يحتوي على بيانات مستخدمين. ملف `.gitignore` يمنع إضافته عند استخدام Git، وإعداد `_config.yml` يستثنيه من ملفات الموقع المنشورة على GitHub Pages. إذا رفعته سابقاً، احذفه من المستودع أيضاً؛ إعدادات النشر لا تحذفه من ملفات المستودع.

## صفحات الموقع

- الصفحة الرئيسية: `index.html`
- تسجيل الدخول وإنشاء الحساب: `login.html` و`register.html`
- الحجز: `booking.html`
- لوحات العرض: `farmer-dashboard.html` و`supplier-dashboard.html` و`mechanic-dashboard.html` و`specialist-dashboard.html` و`admin-dashboard.html`
